# SQL-School-Management-System
SQL School – School Management System

School Management System Database Project developed as part of a university project.

📌 Project Overview

SQL School is a School Management System designed to manage information related to students, teachers, subjects, classrooms, schedules, registrations, and academic records.

The system includes different user roles:

* Student – View personal information, class schedules, grades, and attendance.
* Teacher – View subjects, record grades and attendance, and view student information.
* Admin – Manage system data and user permissions.

🗄️ Database Design

The project includes database design and analysis such as:

* Entity Relationship Diagram (ER Diagram)
* Entity and Attribute Analysis
* Primary Key (PK)
* Foreign Key (FK)
* Composite Primary Key
* Entity Relationships
* Data Dictionary
* Database Tables

📊 Main Entities

The database contains the following main entities:

* Student
* Teacher
* Admin
* Classroom
* Subject
* Schedule
* TSchedule
* School_Record
* Registration

🔗 Database Relationships

Examples of relationships designed in the project include:

* Student → Registration
* Student → School Record
* Student → Classroom
* Teacher → Subject
* Teacher → TSchedule
* Subject → Schedule
* Classroom → Schedule
* Admin → Schedule
* Admin → TSchedule
